# FlowPilot — HexCoded Product Prototype

A lightweight, interactive product concept built specifically around HexCoded and its creative-professional users.

## Concept

FlowPilot turns a creative brief into a reusable AI production workflow, then adds a persistent QA/consistency layer across the workflow.

The concept is designed to complement HexCoded's existing strengths in:
- multi-model image/video generation
- actors
- custom video creation
- URL-to-ad creation

The prototype focuses on a product gap: helping professional creators move from a brief to a controlled, repeatable, production-ready workflow.

## What the demo includes

- Creative brief input
- Visual node-based workflow
- Concept Director agent
- Brand Lock guardrail
- Character Lock guardrail
- Storyboard planning
- Model-routing concept
- Creative QA scores
- Detected issues
- "Fix with Agent" interactions
- Lightweight agent chat simulation

## Run locally

Just open `index.html` in a browser.

For best results, serve the folder with any static server, for example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000

## Deploy

This is a static site and can be deployed directly to Vercel, Netlify, Render Static Sites, GitHub Pages, or Replit.

## Product thesis

Professional creative teams need more than generation. They need continuity, repeatability, production constraints, and fast QA across multi-step AI workflows.

FlowPilot treats the creative brief as a source of truth that persists through the workflow and checks every stage against it.


## Prototype note

This is an interactive product prototype. AI generation and QA results are simulated to demonstrate the intended product experience and workflow.
